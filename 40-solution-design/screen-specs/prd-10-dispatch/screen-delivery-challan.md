# Screen — Delivery Challan

**Module:** PRD-10 Dispatch · **Demo spine:** step ⑯.

The generated challan — **24 fields, 7 header and 17 line** — viewable and printable.

> **A competence screen, not a wow screen.** The challan exists in UdyogERP today and is documented
> field-by-field ([obs-03 §5](../../../10-observations/obs-03-field-catalog.md)). Anyone from accounts
> will check that Phlo produces what they already produce. **Missing a field costs credibility;
> matching them all buys permission to show the interesting screens.**

### Two producers, one document

A delivery challan is generated by **two different flows**:

| Flow | When | Rule |
|---|---|---|
| **Customer dispatch** (this module) | Goods leave for a customer | `REQ-DS-004` |
| **Inter-plant transfer** (prd-06) | Source and destination **share a GSTIN** | `REQ-DS-005`, `REQ-IM-005` |

The rule is the same in both — GSTIN decides — but the second is **document-only in the demo**: prd-08
`A-SCH-04` covers customer deliveries only, and the fleet is assumed outbound-only (obs-07 §8).

## 3. Data Points Displayed

### Header — 7 fields (obs-03 §5)

| # | Field | Source | Notes |
|---|---|---|---|
| 1 | Date | `.created_at` | |
| 2 | Consignee | `Party`, ship-to | |
| 3 | Series | plant series | |
| 4 | **Export Type** | `"Without IGST"` where applicable | See below |
| 5 | Buyer | `Party`, bill-to | May differ from consignee |
| 6 | **Place of Supply** | consignee state; `"Others"` for export | Determines the GST split |
| 7 | Transaction No. | `P[Unit]/[FY]/DC/[Serial]` | Pyramid's own format, from obs-03 |

Plus, from the dispatch: **vehicle number** and **transport mode** (`REQ-DS-004`).

### Lines — 17 fields

Sr. No. · Supply Name · Quantity · Rate · Addl. Info · Narration · Taxable Value · %CGST · CGST ·
%SGST/UTGST · SGST · %IGST · IGST · Comp. Cess Rate · Comp. Cess · Amount · Receipt.

**All 17 are rendered**, including the ones that are usually blank. `Comp. Cess Rate` shows `NO-CESS`
where that is what the sampled document showed. An accounts person scanning for a familiar field
should find it.

### Export Type is not a leftover

obs-03's sampled challan carries `Export Type = "Without IGST"` and `Place of Supply = "Others"`, with
zero GST. **HANDOVER §7 flags this as a live contradiction** — Pyramid is scoped as not exporting, yet
a real challan shows an export, the Supply Master carries a RODTEP field, and IBCs carry a ~40-country
recollect label.

The field is rendered because the document has it. `[UNKNOWN: whether export dispatches are in scope.
Excluding them is fine; recording "Pyramid does not export" as fact is not — HANDOVER §7.]`

## 4. CTAs

| Control | Behaviour | Event emitted |
|---|---|---|
| **Print** | Browser print, document layout | none |
| **PDF** | Download | none |
| **Back to dispatch** | [Dispatch Detail](screen-dispatch-detail.md) | none |
| **Regenerate** | Rebuilds after a correction upstream | `DELIVERY_CHALLAN_GENERATED` (new version) |
| Buyer / consignee links | Party record | none |

**Nothing is editable here.** The challan is generated from the dispatch (`REQ-DS-004`). A wrong
challan is fixed by correcting the dispatch and regenerating — which keeps the document and the
movement in agreement, and leaves both versions in the event stream.

## 5. Validations

Generation-time, surfaced here if they failed:

| Rule | Message |
|---|---|
| Consignee must have a GSTIN when registered | "Consignee has no GSTIN. GST cannot be computed." |
| Place of supply required | "Place of supply determines the tax split." |
| Vehicle number required | "The challan needs a vehicle number." |
| HSN required per line | "No HSN on WMD-035. GST cannot be computed for this line." |
| Rate required per line | "No rate on line 2." |
| Series must be configured for the plant | "No challan series configured for Unit 7." |

## 6. Conditional States

| State | What the user sees |
|---|---|
| **Loading** | Document skeleton in layout |
| **Generated** | Full document, print-ready |
| **Intra-state** | CGST and SGST columns populated; IGST blank |
| **Inter-state** | IGST populated; CGST and SGST blank. Driven by place of supply against the plant's state |
| **Export type set** | Zero GST, place of supply `Others`, with a note that export scope is unresolved (HANDOVER §7) |
| **Inter-plant, same GSTIN** | Header reads "Stock transfer — not a sale". **Same document, different meaning** — prd-06 §Business Rules: a transfer is a relocation even when a document is required |
| **Missing GSTIN or HSN** | Amber banner naming the field and where to fix it; the document still renders with gaps visible rather than silently zeroed |
| **Superseded** | Where the dispatch was corrected: "Superseded by DC-4412-v2." Both retained |
| **Restricted — plant role** | Viewable and printable; it travels with the truck. Rates visible here because they are **printed on the document itself** — hiding them would be theatre |

The last point is worth stating: elsewhere plant roles do not see rates, but a challan **is** a priced
document that a plant person hands to a driver. The restriction cannot apply where the physical
artefact carries the data.

## Open Questions

1. **Are export dispatches in scope?** The field exists on a real document and the evidence conflicts.
   HANDOVER §7 says: fine to exclude, not fine to record as fact.
2. **What is the challan series per plant?** Format is known (`P[Unit]/[FY]/DC/[Serial]`); the
   configuration is not.
3. **Does the challan print on pre-printed stationery?** Affects layout entirely, and nobody has seen a
   physical one.
4. **Is a challan ever issued without a dispatch** — a sample, a replacement, a warranty return?
5. **Who signs it, and does a copy come back?** The outbound LR carries the POD; whether the challan
   does too is undocumented.
